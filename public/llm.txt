- [NERVI — Local LLM inference on Intel NPU](https://proj.dsainvg.me/nervi): Fully offline local LLM inference on Intel AI Boost NPU via OpenVINO GenAI — Go CLI + TUI frontend, npuserver Flask backend exposing an OpenAI-compatible /v1/chat/completions endpoint, fine-tuned Qwen3-4B INT4 NPU models, and a Cloudflare-backed extension marketplace. [Site](https://nervi.dsainvg.me) · [Docs](https://nervi.dsainvg.me/docs) · [Marketplace](https://nervi.dsainvg.me/marketplace) · [Source](https://github.com/dsainvg/NERVI) · [Report](https://proj.dsainvg.me/data/projects/nervi/reports/NERVI_Project_Report.md)
- [ORCH — Agent Graph Orchestration Language](https://proj.dsainvg.me/orch): A custom DSL for multi-agent systems built end-to-end: OCaml compiler (lexer, parser, semantic analysis, codegen), Python runtime orch-lib on PyPI (v3.3.1), and a TypeScript VS Code extension live on both the VS Code Marketplace and Open VSX (v2.0.0). [Docs](https://dsainvg.github.io/documentation-aeon/) · [PyPI: orch-lib](https://pypi.org/project/orch-lib/) · [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=dsainvg.orch-dsl-language-support) · [Open VSX](https://open-vsx.org/extension/dsainvg/orch-dsl-language-support) · [Source](https://github.com/dsainvg/software_eng_lab_project) · [Report](https://proj.dsainvg.me/data/projects/orch/reports/ORCH_Project_Report.md)
- [MATNETS — Matrix-Neuron Neural Networks in JAX](https://proj.dsainvg.me/matnets): JAX research library replacing scalar neurons with n×n matrix-neurons (tensor contraction via einsum, native jit/vmap/grad); matrix-neuron CNNs reach ~98.5% MNIST at roughly one-third the parameters of a standard CNN. On PyPI as matnets (v3.2.5, Python ≥3.11). [PyPI: matnets](https://pypi.org/project/matnets/) · [Docs](https://dev.dsainvg.me/MATNETS/) · [Source](https://github.com/dsainvg/MATNETS) · [Report](https://proj.dsainvg.me/data/projects/matnets/reports/MATNETS_Report.md)
- [ENIGMA — C++ cryptography library with Python bindings](https://proj.dsainvg.me/enigma): From-scratch C++17 cryptography monorepo with pybind11 bindings — memory-hard password hashing (16×N memoization table, ~70–150 ms at cost=10, password-length-independent) and a rotate+XOR chunked file cipher scaling from 9 MB/s single-threaded to ~22 MB/s at 22 threads within constant ~1.4 MB RAM. PyPI enigma-encryption v1.0.0 with wheels for Python 3.10–3.13 on Windows/macOS/Linux; deliberately unauthenticated (no MAC) — docs recommend AES-GCM/Argon2id for high-security use. [PyPI: enigma-encryption](https://pypi.org/project/enigma-encryption/) · [Live demo](https://enigma-ed.streamlit.app/) · [Docs](https://dev.dsainvg.me/enigma/) · [Source](https://github.com/dsainvg/enigma) · [Report](https://proj.dsainvg.me/data/projects/enigma/reports/enigma_project_report.md)

## AI & Machine Learning Research

- [IPL Mock Auction — Multi-agent LLM simulation](https://proj.dsainvg.me/auction_agents): 10 LLM-powered franchise agents (LangGraph pipeline, DeepSeek v3.1 via NVIDIA API, Chain-of-Thought reasoning) bid on 369 real IPL 2026 mini-auction players with real post-retention purses (₹2.75–64.3 Cr); the report analyzes results against real-world signings (68 of 77 replicated; capped players retain 80.5% of real price vs 12.7% for uncapped). Run on AWS EC2. [Source](https://github.com/dsainvg/auction_agents) · [Report (PDF)](https://proj.dsainvg.me/data/projects/auction_agents/Mock_IPL_Auction.pdf)
- [Tic-Tac-Toe AI — Neural network game opponent](https://proj.dsainvg.me/hosted-tictactoe): Web Tic-Tac-Toe against a 5-layer PyTorch feedforward network trained from scratch (masked logits over occupied cells), served live via Streamlit; the companion repo (Tic-tac-toe-model) holds the training notebook and model weights. [Live](https://tik-tac-toe.streamlit.app/) · [Source](https://github.com/dsainvg/hosted-tictactoe) · [Training model](https://github.com/dsainvg/Tic-tac-toe-model)
- [Electric Charge Distribution — Numerical physics simulation](https://proj.dsainvg.me/electric-charge-distribution): Python simulation of induced surface charge density on a neutral conducting sphere near an external point charge — 10,000-point Fibonacci lattice, constrained gradient descent (neutrality + L2 smoothing), validated against a 50-term Legendre series at >97% similarity, with interactive 3D Plotly visualization. [Source](https://github.com/dsainvg/Electric-Charge-Distribution) · [Interactive demo](https://dev.dsainvg.me/Electric-Charge-Distribution/) · [Case study](https://proj.dsainvg.me/data/projects/electric-charge-distribution/reports/ElectricChargeDistribution_HiringReport.md)
- [Circuit Diagram Generator — CSV to digital-logic schematics](https://proj.dsainvg.me/circuit_diagram_generator): Python tool that renders digital-logic circuit diagrams (74-series ICs: AND/OR/NOT/NAND/XOR/MUX) from structured CSV inputs (chips + connections), routing orthogonal connections via channel-routing/layout algorithms and rendering SVG → PNG (cairosvg/Pillow). [Source](https://github.com/dsainvg/circuit_diagram_generator)
